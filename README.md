## 🛠️ 개발 환경

- **프로그래밍 언어**: jsp, javascript
- **IDE**: Eclipse
- **DBMS**: Oracle Database
- **SQL 툴**: SQL Developer
- **버전 관리**: GitHub

## ✨ 프로젝트 목적
### 목표: 기존 프로젝트 CLI 환경을 front 화면으로 구현
### 주제 : 코로나 이후 활발해진 여행 시장에서 다양한 경험 공유를 위해 여행 플랫폼 디자인
